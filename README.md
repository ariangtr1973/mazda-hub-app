# Mazda Hub

Home screen app for the in-car Galaxy Tab S6. It shows the hub page (clock, directions/weather swipe pane,
now playing with visualizer) full screen and can be set as the tablet's home app.

The hub page lives in `app/src/main/assets/index.html`.

Every push to `main` builds the app on GitHub. Download `app-debug.apk` from the **latest** release
(Releases, on the right of the repository page) and open it on the tablet.
